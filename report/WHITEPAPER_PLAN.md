# 白皮书阶段实施计划

目标：形成一份可用于 A02 立项评审、技术评审和后续 MVP 启动的风险驱动论证白皮书。

## 成功标准

- 白皮书包含执行摘要、PEA 立项论证、风险登记表、开源复用评估、四阶段路线图、POC 预研报告、一期边界与立项建议。
- 风险登记表覆盖 260522 总体方案中最有野心、最容易被质疑的承诺。
- POC 数据被明确引用，且不夸大：只证明合成+扰动场景下 L1 经验结构化闭环可跑通。
- 白皮书能回答一个实际问题：如果要建设焊接技能大师平台，第一期到底应该做什么、不做什么、为什么值得做、需要什么资源、如何验收。

## 工作分解

### Task R1：白皮书工作区

- 建立 `report/` 目录。
- 固化 POC 证据快照到 `report/data/` 和 `report/assets/`。
- 写 `report/README.md`。

验证：目录结构清晰；证据文件可被白皮书引用。

### Task R2：白皮书主体

- 写 `船舶焊接工艺大脑平台_风险驱动论证白皮书.md`。
- 第 0 部分执行摘要最后回填。
- 风险登记表用标签和处置区分“能做、需投入、需预研、暂不承诺”。

验证：章节完整；风险表与 POC 数据一致；没有把 L2/L3 说成已完成。

### Task R3：自审与评测

- 写 `WHITEPAPER_REVIEW.md`。
- 对照北极星、PEA、风险表、路线图、POC 证据、一期开工价值逐项检查。

验证：每一项有明确结论；问题和后续动作不藏起来。

### Task R4：后续交付

- 根据评审需要导出 HTML/docx。
- 如需要对外汇报，可再提炼一页执行摘要和 5-8 页汇报版。

验证：导出文件在 `report/exports/`，与 Markdown 主文一致。
