一、方案总述

船舶焊接工艺大脑平台定位为面向船舶海工焊接场景的工艺知识中枢、经验复现中枢、自动化作业中枢和质量闭环中枢。平台以“焊缝对象”和“工艺包”为核心，将技能大师经验、坡口与焊缝视觉数据、机器人轨迹、焊接电参数、力控数据、熔池视频、声纹信号、焊后检测结果统一纳入同一数据链路，形成可沉淀、可复用、可执行、可追溯、可持续优化的船舶焊接工艺能力。

本项目面向船舶制造与海工装备焊接中工作量大、质量要求高、厚板高强钢焊接难度高、复杂坡口调试周期长、技能经验难传承、数据孤岛严重、质量管控滞后等问题，建设以智能化、数字化、标准化为导向的焊接工艺大脑平台。平台不是单一 AMR 焊接机器人，也不是单独的视觉轨迹规划软件，而是将视觉识别、工艺知识库、轨迹规划、移动机器人执行、焊中监测和焊后质量评价组织成一条完整的工艺闭环。

平台建设的主链路为：焊缝任务与对象建模 -> 焊前坡口扫描与识别 -> 工艺包匹配与多层多道规划 -> 轨迹拟合与仿真校核 -> AMR/机器人作业执行 -> 焊中多源数据采集 -> 焊后形貌检测与质量评价 -> 工艺参数、轨迹模板和经验模型迭代入库。所有建设内容围绕该主链路展开，避免把设备、软件模块或数据看板割裂为孤立能力。

二、项目定位与系统边界

2.1 平台定位

船舶焊接工艺大脑平台的核心定位是“船舶焊接工艺数字化与智能决策平台”。其主体价值不在于简单替代人工焊接，而在于把船舶厚板、高强钢、复杂坡口、多层多道、长焊缝和大构件作业中的工艺经验转化为可计算、可执行、可验证、可持续优化的标准化工艺包，并通过机器人系统完成稳定复现和质量闭环。

  • 工艺知识中枢：沉淀材料、板厚、接头形式、坡口类型、焊接位置、焊材、保护条件、焊接参数、层道策略、摆动方式和质量结果之间的关联关系。
  • 经验复现中枢：将技能大师的焊枪姿态、行进速度、干伸长度、摆动方式、停留节奏、修正动作、熔池状态和质量结果转化为机器可执行模型。
  • 自动化作业中枢：通过焊前扫描、轨迹规划、AMR 移动覆盖、六轴机器人执行、焊后扫描和复检支撑柔性自动化作业。
  • 质量闭环中枢：把焊前、焊中、焊后数据与缺陷结果关联，反向优化轨迹规划、工艺参数、层道策略和经验模型。

2.2 系统边界

边界项纳入范围边界说明
工艺对象船舶海工焊接中的典型坡口焊缝、角焊缝、厚板多层多道焊缝、机器人可达焊接场景。不泛化为所有制造行业的通用工艺平台，优先聚焦船舶焊接核心场景。
平台主体焊接工艺数据标准、工艺知识库、经验采集、视觉识别、轨迹与工艺协同规划、机器人作业执行、质量闭环分析。不替代既有 ERP、MES、PLM、QMS、WMS 等企业管理系统，只对接必要业务数据。
硬件关系AMR 移动底座、六轴机器人、激光扫描、力控、熔池视频、声纹、电参数采集、焊接电源等作为采集和执行载体。硬件清单不是项目目标，硬件服务于工艺大脑主链路。
自动化边界支持焊缝识别、工艺推荐、轨迹生成、仿真校核、人工确认后的机器人执行、焊后检测和质量反馈。默认采用“人在回路”的高可靠自动化，不把未经验证的全无人自主焊接作为初始边界。
数据边界以焊缝、层、道、工艺包、轨迹、设备、质量结果和版本为核心数据对象。通用行政、财务、人事、采购等业务数据仅作为外部系统引用，不在本平台重复建设。

2.3 能力来源划分

能力类型主要内容平台处理原则
现有基础能力既有焊接工艺文件、工艺评定资料、焊缝质量判据、现场焊接经验、设备运行数据和质量检测结果。结构化沉淀为焊缝档案、工艺包、质量样本和专家规则。
采购集成能力AMR 移动底座、六轴工业机器人、三维激光扫描仪、线激光轮廓传感器、六维力传感器、熔池高速相机、声纹采集、电参数采集、图形工作站、同步采集模块。统一完成接口接入、坐标标定、时间同步、设备状态采集和作业指令管理。
重点研发能力工艺参数体系、经验特征提取、多层多道规划、轨迹与工艺协同生成、质量关联分析、工艺推荐模型、缺陷归因和版本迭代机制。围绕船舶焊接工艺机理和验证数据持续迭代，形成平台核心能力。
联合验证能力典型焊缝样本、技能大师采集样本、试板验证、现场工况复核、质量判据确认、返修原因复盘。由工艺人员、操作人员、质量人员与平台共同形成确认规则和入库标准。
复用对接能力用户权限、任务信息、图纸/工艺文件、质量结果、设备台账、生产看板和报表。通过接口引用和数据对接实现互联互通，避免增加不必要系统实体。

三、建设目标与核心价值

平台建设目标是构建面向船舶焊接的“工艺数据资产 + 经验模型 + 自动化执行 + 质量反馈”一体化能力，推动焊接生产从个人经验驱动转向数据、规则、模型和验证共同驱动。

目标方向建设目标形成价值
工艺标准化建立统一焊缝对象、坡口参数、焊接参数、轨迹特征、层道策略、质量结果和版本管理模型。让经验、参数、轨迹和质量结果可沉淀、可检索、可复用、可追溯。
调试高效化将典型焊缝的工艺包、摆动模板、层道策略和轨迹规划能力复用到相似场景。降低机器人编程和工艺调试对个人经验的依赖。
作业自动化形成从焊前识别、工艺匹配、轨迹规划、AMR 移动覆盖、机器人执行到焊后检测的作业链路。提高跨工位、大构件、长焊缝和柔性作业覆盖能力。
决策智能化通过工艺规则、质量样本和数据模型生成工艺推荐、轨迹优化和质量风险提示。将质量控制从事后记录提升为事前推荐、事中监控和事后优化。
经验传承化采集并结构化技能大师焊接手法、参数选择、熔池判断和缺陷修正经验。把不可复制的个人经验转化为可学习、可训练、可复现的组织能力。

四、总体技术架构

4.1 主链路架构

焊缝任务与对象建模 -> 焊前坡口扫描与识别 -> 工艺知识匹配 -> 多层多道与轨迹协同规划 -> 仿真校核与人工确认 -> AMR/机器人自动执行 -> 焊中熔池、声纹、电参数和轨迹同步采集 -> 焊后焊道扫描与质量评价 -> 缺陷归因、工艺优化和版本入库。

总体架构以焊缝为最小业务对象，以工艺包为核心输出，以质量反馈为闭环入口。平台从焊缝任务、图纸工艺要求和现场扫描数据出发，完成焊缝几何理解、工艺参数匹配、层道与轨迹规划，再由 AMR 和机器人完成移动覆盖、扫描、焊接和复检，最终将焊接质量结果回写到工艺知识库。

架构层级核心能力关键输出
设备与采集层接入 AMR、机器人、三维/线激光、力控、焊接电源、熔池相机、声纹、电参数采集、质量检测设备。设备状态、原始点云、机器人位姿、关节数据、电参数、力控、视频、声纹、检测结果。
IOT 与同步层支撑 MQTT、Kafka、HTTP/HTTPS、OPC、Modbus、RS485/232 等协议接入，完成实时采集、数据解析、时间戳管理、指令交互和边缘计算。统一时间轴数据、设备事件、过程采集数据和可追溯采集记录。
工艺知识层建立材料、板厚、坡口、焊材、焊接位置、参数窗口、层道策略、摆动模板、质量判据、返修规则。船舶焊接工艺知识库、经验样本库、缺陷样本库和质量关联样本。
规划决策层完成坡口识别、工艺推荐、多层多道规划、焊枪姿态生成、摆动参数配置、轨迹拟合、仿真校核和风险提示。机器人可执行轨迹、工艺参数包、层道作业计划、AMR 停靠位姿和仿真校核结果。
执行闭环层控制 AMR 定位覆盖、机器人扫描/焊接/复检，采集过程数据并关联焊后形貌、探伤和返修结果。作业记录、质量评价报告、缺陷关联分析、工艺优化建议和入库版本记录。
应用呈现层提供工艺管理、经验采集、视觉规划、作业执行、质量分析、统计看板、智慧大屏和接口服务。面向工艺、操作、质量和管理角色的统一应用入口。

4.2 主数据对象

数据对象主要字段作用
焊缝对象焊缝编号、构件编号、接头形式、焊接位置、坡口类型、空间坐标、质量等级、适用工艺包。作为数据归档、工艺匹配、轨迹规划和质量追溯的统一索引。
坡口对象坡口角度、间隙、钝边、深度、宽度、错边量、断面面积、焊缝走向、曲率。支撑填充量计算、焊枪姿态、摆动方式和层道策略选择。
工艺包焊接方法、焊材、保护条件、参数窗口、层道策略、摆动模板、质量判据、适用条件、验证记录。形成机器人执行和工艺复用的核心载体。
层道对象层序、道序、道间搭接、填充面积、焊接顺序、清理检查点、层间温度约束。支撑厚板多层多道稳定成型和质量控制。
轨迹对象TCP 路径、焊枪姿态、行进速度、摆动幅度、摆动频率、停留时间、起收弧、过渡点。支撑轨迹复现、仿真检查和机器人程序生成。
过程状态对象电流、电压、送丝速度、焊速、热输入、力控数据、熔池特征、声纹特征、设备状态。支撑焊中监控、异常识别和质量关联分析。
质量对象焊道宽度、余高、咬边深度、焊趾过渡角、外观缺陷、探伤结果、返修记录、质量结论。支撑质量追溯、缺陷归因和工艺优化。

五、焊接工艺参数体系与工艺知识库

工艺大脑的核心不是单条轨迹，而是“焊接对象、工艺参数、运动手法、过程状态和质量结果”的完整映射。平台需要把船舶焊接经验拆解为可计算参数，并与焊接结果形成稳定关联。

5.1 工艺参数体系

参数域关键数据用于支撑
焊接对象材料牌号、板厚、构件类型、接头形式、焊接位置、拘束条件、坡口形式、质量等级。确定工艺适用范围、焊接方法选择、质量判据和风险提示。
坡口几何坡口角度、根部间隙、钝边高度、坡口深度、坡口宽度、错边量、断面面积、焊缝曲率。确定填充体积、层道数量、焊枪姿态、扫描路径和焊接路径。
焊接材料焊丝/焊条型号、直径、保护气体、焊剂、母材批次、材料状态。约束电参数窗口、热输入、熔敷效率和质量追溯。
电参数电流、电压、送丝速度、焊接速度、极性、脉冲参数、热输入、预热温度、层间温度。支撑工艺推荐、过程监控、缺陷预警和参数优化。
运动参数焊枪工作角、行进角、干伸长度、摆幅、摆频、左右停留、起收弧、层间过渡。支撑大师经验复现、机器人轨迹生成和多层多道协同。
层道参数打底、填充、盖面层数，道次数量，道间搭接，清根/清渣节点，分段顺序，暂停检查点。支撑厚板坡口稳定填充、变形控制和质量一致性。
过程状态熔池长度、宽度、面积、长宽比、声纹时域/频域特征、力控状态、设备事件。支撑焊中状态识别、异常标注和经验模型训练。
质量结果余高、宽度、咬边、焊趾过渡、气孔、未熔合、未焊透、探伤结果、返修原因。支撑质量闭环、工艺包版本迭代和经验模型修正。

5.2 工艺包定义

平台以“工艺包”作为标准化输出。一个工艺包对应一类焊接对象和一组适用条件，既包含工艺参数，也包含层道策略、轨迹模板、质量判据和验证证据。工艺包不替代既有焊接工艺评定和施工方案管理，而是将其转化为机器人可执行、质量可追溯的数据化表达。

  • 对象条件：材料、板厚、接头形式、坡口类型、焊接位置、质量等级和适用范围。
  • 工艺参数：焊接方法、焊材、保护条件、电流、电压、送丝、焊速、热输入、预热和层间温度控制要求。
  • 层道策略：打底、填充、盖面层数，道次排列，道间搭接，道间清理，清根/清渣/检测节点和层间约束。
  • 运动模板：焊枪姿态、摆动方式、摆幅、摆频、左右停留时间、起收弧和转角过渡策略。
  • 质量判据：焊道形貌、尺寸偏差、缺陷阈值、探伤要求、返修规则和入库验证记录。
  • 版本规则：原始建议、人工修订、试焊验证、质量确认和正式发布均保留版本记录。

5.3 工艺知识库建设内容

工艺知识库应覆盖船舶海工厚板、高强钢、复杂坡口、典型焊接位置和多层多道作业场景，形成“规则 + 样本 + 模型 + 版本”的复合知识体系。

  • 基础规则库：材料、板厚、接头、坡口、焊接位置、焊材、电参数窗口、热输入限制、层间温度要求。
  • 摆动模板库：平焊、立焊、横焊等典型位置下的月牙形、锯齿形、8 字形、梯形摆弧等模板及可调参数。
  • 层道策略库：针对不同坡口截面和填充体积的打底、填充、盖面层道排列规则。
  • 质量缺陷库：咬边、余高异常、未熔合、未焊透、气孔、飞溅、变形等缺陷与参数、轨迹、层道之间的关联样本。
  • 经验样本库：技能大师轨迹、电参数、熔池、声纹、力控和质量结果的同步样本。
  • 工艺包版本库：记录工艺包从推荐、试焊、修正、验证到正式发布的全过程。

六、大师经验数字化与可复现模型

技能大师经验数字化不是简单记录机器人或人工拖拽轨迹，而是同步记录“在什么对象、什么工艺条件、什么焊接状态下采取了什么手法，焊后质量结果如何”。平台通过柔顺示教、过程采集和质量结果绑定，把经验动作转化为可解释、可复现、可验证的工艺特征。

6.1 全维度焊接轨迹采集

大师经验采集以最小 10ms 时间粒度开展，采样间隔可根据实际场景配置。采集内容覆盖焊接过程全流程：

  • 同步采集焊枪末端空间位姿数据，包括 X/Y/Z 三轴坐标和 Rx/Ry/Rz 三轴姿态参数。
  • 同步记录机器人各关节运动参数，为轨迹拟合、碰撞检查和机器人复现提供底层运动数据。
  • 同步采集拖拽操作过程中的力控数据，为阻抗控制、柔顺示教和操作手感优化提供样本。
  • 同步提取焊枪干伸长度、工作角、行进角、行进速度、摆长、摆幅、摆动频率、左右停留时间和起收弧动作。
  • 将轨迹、电参数、熔池视频、声纹信号、力控数据和焊后质量结果统一绑定到焊缝、层、道和时间轴。

6.2 轨迹回放、裁剪与编辑

采集完成的轨迹数据支持预览、回放、暂停、前进、后退、分段查看和关键区段反复复核。原始轨迹中存在的冗余区段、多余动作、明显抖动和非工艺停顿，应通过轨迹编辑工具进行裁剪和标注。系统在虚拟环境中模拟机械臂和移动设备沿规划路径的运动过程，结合 3D 碰撞检测动态检查其与产品、工装、地面及其他设备的干涉风险。

6.3 经验转化逻辑

七、焊前视觉识别与点云处理

7.1 坡口扫描设备与作业逻辑

焊前坡口扫描采用“柔性 AGV 移动平台 + 升降机构 + 六轴机器人 + 三维激光扫描仪/线激光轮廓传感器”的组合。AMR 提供跨工位移动和粗定位，机器人提供局部精密运动，激光传感器获取坡口点云和轮廓数据，系统通过手眼标定完成传感器坐标、机器人坐标、工件坐标之间的转换。

扫描启动前，操作人员可通过拖拽示教设定扫描起点与终点，系统根据端点自动生成直线扫描轨迹。对于存在形态变化的复杂曲线焊缝，系统结合坡口轮廓点云生成适配性扫描路径，保证扫描覆盖整个坡口区域。扫描过程中，机器人按规划轨迹运动并同步触发激光采集，所有轮廓数据按时间戳有序存储。

7.2 坡口智能识别与参数解算

平台基于扫描点云自动完成坡口类型识别和几何参数解算，并将结果展示在操作界面中。操作人员可对识别偏差、参数异常或特殊工况进行人工修改和复核确认，确认后的数据进入对应焊缝档案，作为轨迹规划和焊接加工的基础数据。

坡口类型可解算关键几何参数数据处理方式输出展示形式

7.3 手眼标定与坐标统一

正式扫描作业前，需要完成机器人与线激光传感器的手眼标定，建立传感器坐标系与机器人本体坐标系之间的转换关系，并将坡口点云统一换算到机器人坐标系和工件坐标系。标定完成后进行精度校验，保障扫描数据、机器人位姿、AMR 停靠位置和工件坐标在空间维度一致，避免坐标转换偏差导致参数解算和轨迹规划失真。

7.4 点云预处理算法体系

焊前坡口和焊后焊道扫描会产生大量原始点云，包含环境干扰、反光噪声、飞溅干扰、离群点和背景平面等无效信息。点云预处理环节覆盖从原始数据导入到可用点云输出的全流程：

  • 统计滤波：计算点到相邻点的平均距离，剔除不符合统计规律的随机噪声和孤立离群点。
  • RANSAC 平面拟合：分离扫描范围外的平面背景干扰，提取目标坡口或焊道区域。
  • 体素降采样：在保留几何特征的前提下降低点云密度，减少后续计算负荷。
  • ICP 点云配准：将不同位姿下采集的多帧点云统一整合到同一坐标系，保障连续性和完整性。
  • 参数可调：在特殊场景下支持人工调整滤波、配准和分割参数，以适配不同焊接场景的数据质量。

平台可兼容 DS-Inspector 等国产自主可控三维测量分析软件能力，支撑三维扫描重建、偏差分析、尺寸测量、点云可视化和结果复核。

7.5 三维可视化交互

完成点云预处理后，平台提供三维渲染和交互复核能力。操作人员可对坡口或焊道点云进行缩放、旋转、平移，切换俯视视角观察焊缝走向；可通过矩形框选添加文字注释；可执行点到点距离测量、选区面积计算、体积计算；所有复核操作、人工修改和标注记录均归档到焊缝档案，保留操作痕迹。

八、轨迹规划、拟合与多层多道工艺规划

8.1 轨迹与工艺协同规划

轨迹规划不单独追求几何路径最优，而是与焊接工艺共同求解。平台在生成机器人路径时同步考虑焊接位置、电参数窗口、焊枪工作角、行进角、干伸长度、摆动模板、层道顺序、热输入约束、AMR 停靠位姿、机器人可达性和质量判据，形成“工艺参数 + 空间轨迹 + 层道计划”的一体化输出。

规划输入规划处理规划输出
坡口点云与焊缝走向坡口参数计算、焊缝中心线提取、路径平滑、坐标转换。扫描轨迹、焊接中心线、机器人基准轨迹。
材料、板厚、接头和焊接位置匹配工艺知识库中的焊材、参数窗口、热输入和质量要求。适用工艺包、参数推荐、风险提示。
大师经验轨迹与摆动模板模板匹配、NURBS/直线/圆弧插补、异常点剔除、工艺特征保留。可执行摆动轨迹、姿态曲线、停留参数。
机器人与 AMR 作业空间可达性分析、碰撞检测、AMR 停靠点规划、分段衔接。机器人程序、AMR 作业位姿、仿真校核结果。

8.2 船舶焊接摆动模板库

平台面向平焊、立焊、横焊等典型船舶焊接位置建立摆动模板库，内置不低于 9 种常用摆动轨迹模板，每个场景至少配置 3 种差异化模板，适配不同焊缝形式与焊接习惯。

  • 月牙形摆动模板：适用于坡口间隙较小的中厚板焊接，可实现熔池充分搅拌，减少气孔等缺陷风险。
  • 锯齿形摆动模板：适配大间隙坡口焊接，保证两侧坡口熔透均匀，控制焊缝余高。
  • 8 字形摆动模板：多用于多层多道焊接盖面工序，获得成型美观、过渡平滑的焊缝表面。
  • 梯形摆弧模板：适用于大钝边、大间隙厚板焊接，保证坡口根部熔透，降低未焊透风险。
  • 参数化调整：支持摆长、摆幅、摆动频率、左右停留时间、行进速度和焊枪角度的参数化配置。
  • 自定义模板：可将经过生产验证的特殊摆动方式保存为模板，纳入版本管理。

8.3 人工轨迹智能拟合

技能大师人工轨迹中存在操作抖动、微小停顿、路径偏移和冗余动作，不能直接转换为机器人可执行路径。智能拟合引擎以标准摆动模板为基础，对原始全维度轨迹进行重构优化，提取核心工艺特征。

  • 同步解析行进速度、焊枪工作角、行进角、干伸长度、摆长、摆幅、左右停留时间、摆动频率等指标。
  • 支持 NURBS 样条插补、直线插补、圆弧插补，将离散轨迹点转换为连续、平滑、机器人可执行的运动路径。
  • 对轨迹拼接处进行过渡处理，避免机器人执行时出现卡顿、姿态突变或不可达状态。
  • 提供拟合结果可视化仿真预览，允许工艺人员对局部参数微调并确认输出。

8.4 多层多道规划逻辑

船舶厚板焊接的关键在于多层多道稳定成型。平台需要从坡口截面、填充体积和工艺约束出发，自动生成打底、填充、盖面的层道结构，并把每一道的轨迹、摆动、参数和质量检查点明确化。

8.5 仿真校核与碰撞检测

平台在轨迹输出前，应在虚拟环境中模拟 AMR、升降机构、机器人、焊枪、传感器、工装、地面和工件之间的空间关系，开展可达性、奇异点、关节限位、干涉碰撞、焊枪姿态和分段衔接检查。对超长焊缝或机器人单站不可达焊缝，系统应结合 AMR 停靠位姿进行分段规划，并在分段重叠区进行轨迹拼接和质量校核。

九、力控柔顺示教与轨迹优化

9.1 阻抗控制柔性拖拽

力控柔顺示教面向技能大师经验采集场景，基于阻抗控制算法搭建机器人柔顺拖拽控制体系。系统应根据平焊、立焊、横焊等不同焊接场景调整力控参数，使不同姿态下拖拽手感保持一致，降低操作人员负担。

  • 重力补偿覆盖机器人全工作空间内的任意姿态，自动解算焊枪和传感器自重影响。
  • 负载标定保证末端工具更换或姿态变化时操作阻力不发生突变。
  • 力控参数支持可视化调整，操作人员可根据个人习惯快速适配。
  • 拖拽过程中的力控数据与机器人位姿数据以不低于 10ms 时间粒度同步存储。

9.2 轨迹平滑优化与特征保留

人工拖拽示教过程中会出现手部抖动、短暂停顿、路径偏移等无效数据。优化算法应在去除无效数据的同时完整保留大师焊接手法特征。

  • 离群点筛选：识别明显偏离焊接路径的异常轨迹点并剔除。
  • 停顿识别：区分工艺停留与无意义停顿，保留焊接需要的停留时间参数。
  • 滑动窗口滤波：根据轨迹曲率自动调整窗口大小，直线段增强平滑，曲线段保留弯曲特征。
  • 原始与优化并存：优化结果与原始数据并列存储，支持对比查看、恢复和重新优化。

十、熔池视频、声纹与工艺多源同步

10.1 熔池形态智能识别

熔池视频分析模块围绕大师经验数字化采集和焊中状态监测展开。视频数据按焊接试验和焊缝档案规则归档，支持按焊缝、层、道和时间段调取。

  • 在焊接强光环境下自动识别熔池区域，提取熔池轮廓边界，降低弧光干扰。
  • 自动提取熔池长度、宽度、面积、长宽比等形态特征参数。
  • 支持操作人员对熔池区域边界和特征参数进行复核与修正，保留修改记录。
  • 将熔池特征与轨迹参数、力控数据、电参数、声纹特征和质量结果关联存储。

10.2 声纹-视频-工艺同步

平台建立焊接多源数据时间轴统一机制，使声纹信号、视频帧、机器人位姿、电参数、力控数据和工艺事件可以在同一时间基准下回放与分析。

  • 熔池视频与焊接过程时间轴同步播放，支持逐帧查看、慢放播放和分段截取。
  • 声纹波形与熔池视频、焊接参数同步展示，辅助观察不同熔池状态对应的声纹变化。
  • 自动提取声纹时域特征和频域特征，并与对应时间段的焊接参数、熔池形态和质量结果建立映射。
  • 多源同步误差以 10ms 级时间戳为目标进行控制，满足经验分析和质量关联对同步精度的要求。

十一、AMR 移动作业与机器人自动化逻辑

AMR 在本平台中的价值不是单纯承载机器人，而是解决船舶大构件、多工位、长焊缝和柔性调度下的作业覆盖问题。AMR 提供跨工位移动、粗定位、安全避障、自动充电和作业姿态切换；机器人、视觉传感器和局部标定负责焊缝级精定位、扫描、焊接和复检。

11.1 作业模式

作业模式适用场景关键逻辑

跨工位模式多工位、多构件连续作业。AMR 按任务顺序移动，到位后通过局部扫描完成工件坐标校准，再启动机器人作业。

经验采集模式技能大师示教、试板验证和工艺样本采集。AMR 和机器人提供稳定采集平台，同步记录轨迹、力控、视频、声纹、电参数和质量结果。

十二、焊后扫描、质量检测与闭环优化

12.1 焊道形貌三维重建

焊后扫描沿焊前扫描生成的既定路径执行，无需重复设置路径参数。系统依托线激光传感器获取每一位置的焊道轮廓数据，结合机器人实时位姿信息，生成焊道全长度着色三维点云，完整还原焊道成型后的实际形貌。

  • 逐帧提取焊道余高、焊道宽度、边缘咬边深度、焊趾过渡角度等形貌参数。
  • 支持焊道点云缩放、旋转、平移和任意视角查看。
  • 同步完成噪声滤波和离群点去除，降低反光、飞溅和环境干扰影响。
  • 重建结果以标准化格式存储，供轨迹拟合、质量分析和工艺优化调用。

12.2 焊前焊后形貌对比

焊前坡口点云与焊后焊道点云统一存储于机器人坐标系和工件坐标系下，可直接进行坐标对齐和形貌变化对比。

  • 基于同一断面位置计算实际填充面积与设计坡口断面面积的差值，评估填充饱满程度。
  • 自动识别焊道边缘与母材过渡位置的形貌差异，提取咬边、余高不足、余高过高等缺陷参数。
  • 将缺陷位置、尺寸、严重程度与原始扫描数据、焊接工艺参数和机器人轨迹绑定存储。
  • 在 UI 中展示焊前焊后轮廓叠加效果，支持人工复核与补充标注。

12.3 质量闭环机制

质量闭环是工艺大脑区别于普通数据采集系统的关键。焊后扫描和检测结果不能只作为记录归档，而要反向驱动工艺参数、层道策略、轨迹模板和经验模型的优化。

质量问题可能关联因素闭环反馈动作
咬边或焊趾过渡差焊枪角度、摆幅、边缘停留、焊速、电压、盖面道排列。调整摆动模板、边缘停留时间、盖面道位置和参数窗口。
未熔合或未焊透热输入不足、根部间隙偏差、打底参数、坡口识别误差、层道顺序。修正坡口参数、打底工艺、层道填充策略和电参数下限。
余高过高或填充不足送丝速度、焊速、道次数量、摆动宽度、填充体积计算、层间搭接。重新计算填充体积，优化道次排列和送丝/焊速组合。
气孔或飞溅异常保护气体、焊材状态、熔池稳定性、弧长、电压波动、现场环境。形成异常标签，关联熔池/声纹特征并提示工艺和现场检查项。
变形或尺寸偏差热输入、焊接顺序、拘束条件、分段策略、层间温度。优化焊接顺序、热输入窗口、分段规划和层间控制规则。

闭环入库遵循以下原则：原始数据、人工修正、模型建议和最终质量结果均保留版本记录；未经质量验证的参数调整只作为建议，不直接覆盖标准工艺包；经重复验证稳定有效的参数、轨迹和层道策略，按版本升级进入标准工艺库；缺陷样本与合格样本同时沉淀，支撑后续质量预判和工艺推荐模型训练。

十四、硬件与支撑环境要求

硬件系统作为工艺大脑的数据采集和自动化执行基础，应围绕“移动覆盖、精密执行、视觉感知、柔顺示教、过程采集、计算分析、同步控制”配置，所有硬件均服务于焊缝对象和工艺包闭环。

十五、关键技术原则

  • 以工艺机理为底座：AI 模型用于增强推荐和关联分析，不能脱离焊接工艺规则、质量标准和现场验证。
  • 以焊缝对象为索引：所有扫描、轨迹、参数、视频、声纹和质量结果都绑定到焊缝、层、道和版本。
  • 以坐标和时间同步为基础：机器人、AMR、激光、相机、声纹、电参数和质量结果必须可在同一坐标和时间轴下关联。
  • 以多层多道为核心难点：厚板焊接必须同时解决填充体积、层道排列、参数分层、热输入、变形和质量检查。
  • 以人在回路保证可靠性：关键工艺变更、异常执行、返修后再规划和标准工艺包升级需要工艺人员确认。
  • 以开放集成为边界：平台优先对接既有系统和设备，不重复建设企业已有管理能力。
  • 以验证数据驱动升级：工艺包、经验模型和质量规则必须通过焊接结果验证后形成稳定版本。
