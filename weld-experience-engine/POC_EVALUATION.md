# 焊接经验结构化 POC 自审与评测记录

日期：2026-05-30

## 目标对照

本 POC 的目标是验证最小闭环：

```text
合成理想大师轨迹
-> 注入真实扰动
-> decompose 为结构化工艺参数
-> recompose 为机器人可执行轨迹
-> metrics 量化复现误差与抗扰动失效边界
```

## 已完成能力

- 工艺数据结构：`Trajectory`、`WeaveTemplate`、`GrooveGeometry`、`LayerPass`、`WeldProcess`。
- 合成数据：直线平焊场景下，按行进速度、摆动模板、摆幅、摆频生成理想轨迹。
- 扰动注入：手抖、路径漂移、无效停顿。
- L1 结构化：中心线提取、行进速度估计、摆幅/摆频检测、模板分类、姿态估计。
- 轨迹重组：结构化 `WeldProcess` 重新生成机器人可执行轨迹。
- 证据输出：往返误差、参数误差、抗扰动失效边界、PNG 图、JSON 摘要、CSV 数据。
- 扩展验证：已注册 8 字形摆动模板，验证模板注册表可扩展。

## 自审结论

- POC 已完成阶段一闭环，可以为白皮书第 5 部分提供关键预研证据。
- 证据只覆盖“合成理想轨迹 + 人工扰动”的半真实场景，不能替代真机采集结论。
- 当前中心线提取仅覆盖直线焊缝/平焊近似，曲线焊缝、多层多道真实几何尚未验证。
- `decompose` 对无效停顿已有基础鲁棒性，但尚未识别左右工艺停留时间。
- 当前分类方法基于波形谐波特征，可解释、轻量，但真机噪声和不同大师习惯下需要再标定。
- `recompose` 在缺少 scipy 时会回退到正向合成轨迹；若后续需要控制器级轨迹平滑，应补齐真实插补库与控制器节拍验证。

## 白皮书使用建议

- 可把“L1 经验结构化”标为已通过合成+扰动 POC 初步验证。
- 可把“抗扰动失效边界”作为诚实风险边界写入风险登记表。
- L2 泛化仅能作为探针讨论，不宜承诺自动适配新坡口。
- L3 焊中熔池闭环自适应仍应列为暂不承诺。
