焊接技能大师平台
项目同步总览

面向机器人、工艺、工程、软件与项目团队的阶段同步页。目的：统一“为什么做、现在做到哪里、下一步怎么协同”。

更新时间：2026-06-02 当前阶段：MVP + 仿真优先资料底座第一轮完成 主路径：公开资料约束 + 轻量仿真 + 可追溯报告

1. 背景

业务背景

船舶制造焊接任务多、工况变化多、自动化落地难。仅靠口头经验和静态工艺卡，难以支撑机器人复用、评测和持续迭代。

项目目标

把焊接技能大师的动作、参数、判断和适用边界，转成可记录、可分析、可复现、可迁移的数据资产。

当前路线

先用仿真和公开资料建立数据闭环与证据闭环；真机和专家经验作为后续标定、验证和审查，不作为当前主路径。

2. 要解决的核心问题

问题 为什么重要 当前应对
经验如何结构化 没有结构化，就无法沉淀技能包，也无法复用和评测。 用轨迹、姿态、速度、摆动模板、过程参数等字段表达技能。
技能如何迁移 船舶焊缝条件变化频繁，技能必须能适配相近任务。 用 `SkillDataset -> WeldSkillPackage -> TransferExperiment` 跑通最小闭环。
仿真参数从哪里来 纯拍脑袋的仿真样本没有工程说服力。 建立资料底座 gate，用公开资料、数据集、字段覆盖和任务证据约束仿真。
如何避免过度承诺 仿真和公开资料不能等同于真实焊接质量验证。 报告明确标注来源、假设、边界和后续需真机验证的字段。

3. 总体思路

路线从“先等真机数据”调整为“先把可控的数据与证据底座做实”。这样成本可控、节奏可控，也能提前让机器人、工艺和工程团队看到可讨论的任务族、字段和报告。

01

船舶任务族

从船舶制造典型任务出发，而不是从通用直线焊倒推。

02

公开资料

整理厂商案例、工艺指南、标准入口和公开数据集。

03

字段覆盖

标注哪些字段有来源，哪些仍是假设。

04

仿真样本

生成可追溯的 `SyntheticSkillDataset v2` 小批量样本。

05

技能包迁移

提取技能包，做相近任务迁移和评测。

06

真机标定

后续用真实焊接、检测和专家审查校准关键字段。

4. 已完成事项

已完成 经验结构化 POC

  • 把合成“大师轨迹”拆解为结构化工艺参数。
  • 支持轨迹重组、误差评估和失效边界分析。
  • 证明“动作经验可以进入数据结构”。

已完成 技能迁移 MVP

  • 建立 `SkillDataset`、`SkillSample`、`WeldSkillPackage`、`TransferExperiment`。
  • 跑通仿真样本、技能包提取、迁移规则和评测报告。
  • 证明“技能包可以迁移到相近焊缝条件”。

已完成 仿真优先知识闸门

  • 从船舶制造任务族选择候选仿真场景。
  • 明确不以真机采集和专家访谈作为当前主路径。
  • 本阶段不纳入焊中闭环或熔池路线。

已完成 资料底座 gate

  • 建立 `docs/data-foundation/` 中文资料卡、manifest 和报告。
  • 用测试校验来源、数据集、字段覆盖和任务证据。
  • 输出 `SyntheticSkillDataset v2` 规划输入。

6. 各团队关注点

团队 当前需要参与的内容 不需要现在解决的内容
工艺团队 确认任务族、接头形式、关键参数字段、哪些字段必须 WPS 或评定后才能定值。 不要求一次性给出所有真实工艺参数。
机器人团队 确认轨迹、姿态、可达性、碰撞、节拍和多焊缝序列字段是否够用。 不要求当前完成真实机器人程序和产线控制接口。
工程团队 确认船舶制造环节、构件对象、典型场景优先级和现场约束。 不要求当前组织大规模真机采集。
软件团队 维护 `SkillDataset`、资料底座 gate、报告生成、测试和后续小批量生成流程。 不急于开发完整生产级平台 UI。
项目团队 把阶段成果表述为“数据结构和证据闭环跑通”，避免对外过度承诺。 不把仿真报告写成真实焊接质量验收结论。

7. 后续事项

下一步 SyntheticSkillDataset v2 小批量设计

  • 优先选 2-3 个 ready 任务族。
  • 定义样本 schema、字段来源、假设字段和报告格式。
  • 先小批量生成，验证流程和评测协议。

下一步 任务族继续收敛

  • 围绕加筋板、板拼、多短焊缝、双层底内部角焊补证据。
  • 把工程语境转成仿真可用字段。
  • 明确哪些任务暂缓到第二轮。

后续 真机与专家审查

  • 把真机采集作为标定和验证，不作为当前主路径。
  • 把专家经验转成字段、规则和人工复核点。
  • 建立仿真结果与真实检测结果的对齐机制。

后续 工程化平台

  • 在数据闭环稳定后再进入平台界面和集成接口。
  • 优先保留报告、版本、来源追溯和评测协议。
  • 逐步对接机器人、焊机、传感器和生产系统。

8. 边界与风险

不能说 真实质量已验证

当前证据来自软件原型、仿真样本、公开资料和 manifest gate，不能替代焊材、焊机、工艺评定和检测结果。

不能混淆 资料底座与批量数据

资料底座 gate 已完成，但 `SyntheticSkillDataset v2` 还没有进入批量生产阶段。

本阶段排除 焊中闭环路线

当前阶段不做熔池图像、熔池控制、声纹归因或实时闭环控制。

推荐对外表述：我们已经跑通焊接技能结构化、迁移评测、仿真优先知识闸门和资料底座 gate，可进入 `SyntheticSkillDataset v2` 小批量设计；真实焊接质量仍需后续真机标定和工艺验证。
