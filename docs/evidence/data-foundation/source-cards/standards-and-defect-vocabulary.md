# 标准与缺陷词汇资料卡

本组资料覆盖公开标准入口、公开焊接工艺规程说明、缺陷词汇指南和海工/船舶语境中的焊接缺陷解释。它们用于统一字段命名、缺陷标签、检查参考和后续报告术语。

使用边界：

- 可用于 WPS 概念、工艺变量、缺陷名称和检查参考的术语约束。
- 可用于提示哪些字段必须在后续真实验证阶段补证。
- 不能替代 AWS 标准正文、客户规范、船级社规则或项目 WPS。
- 不能把公开词汇解释当作真实焊接质量判定。

机器可读权威记录在 `../manifests/sources.json` 和 `../manifests/field_coverage.csv`。本 Markdown 只做人工说明，若与 JSON/CSV 不一致，以 JSON/CSV 为准。
