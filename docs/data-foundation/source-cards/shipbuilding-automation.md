# 船舶焊接自动化资料卡

本组资料覆盖船舶制造中的协作机器人、面板线、分段/小组立、块体焊接和机器人编程案例。它们适合支撑任务族选择、制造阶段、焊接对象、机器人姿态边界、焊枪角度、轨迹模板和可达性假设。

使用边界：

- 可用于识别船舶场景、典型构件、任务优先级和仿真输入字段。
- 可用于为 `SyntheticSkillDataset v2` 规划提供任务证据。
- 不能替代船厂真实工艺规程、设备控制器数据或焊接质量验证。
- 不能从公开宣传资料推导真实产线合格率、缺陷率或质量结论。

机器可读权威记录在 `../manifests/sources.json`、`../manifests/field_coverage.csv` 和 `../manifests/task_evidence_map.json`。本 Markdown 只做人工说明，若与 JSON/CSV 不一致，以 JSON/CSV 为准。
