# 工艺指南资料卡

本组资料覆盖 GMAW、FCAW、MIG/MAG 等公开工艺指南，以及公开页面中可审查的电流、电压、送丝、焊接速度、接头准备和参数选择说明。它们主要用于提供工艺参数的保守范围、字段命名和后续筛选线索。

使用边界：

- 可用于参数字段存在性、通用参数范围和工艺术语对齐。
- 可用于说明某些字段需要客户 WPS 或项目内部规程再确认。
- 不能把通用指南直接当作船舶专用 WPS。
- 不能把指南中的参数当作真实质量验证结果。

机器可读权威记录在 `../manifests/sources.json` 和 `../manifests/field_coverage.csv`。本 Markdown 只做人工说明，若与 JSON/CSV 不一致，以 JSON/CSV 为准。
