# Strategy Documents

本目录用于沉淀 A02「焊接技能大师平台」向创业方向演化时的内部战略判断。

这里的文件不是融资路演 BP，也不是对外宣传材料，而是给初始团队统一方向、边界和判断标准的内部材料。它回答的是：

- 我们是谁；
- 我们做什么；
- 我们不做什么；
- 为什么从焊接切入 Physical AI；
- 我们的客户是谁；
- 当前技术项目如何映射到未来公司战略；
- 怎样判断方向是否跑偏。

## 使用方式

建议先读一页纸战略版，再读方向备忘录，最后用映射表回看当前项目中的模块和证据链。

如果后续项目方向、客户判断、核心对象或不做事项发生变化，应优先更新本目录，而不是直接改产品路线或技术计划。
