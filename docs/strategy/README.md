当前项目级重构以“Physical AI 公司顶层战略与方向”为依据，把仓库默认主线收束到 `WeldSkillPackage` / 工业技能资产。

上一版材料已经合并为两份核心文件：

- [公司顶层战略与方向](2026-06-04-PhysicalAI公司顶层战略与方向.md)：定义这家公司是谁、做什么、不做什么、客户是谁，以及为什么从焊接切入 Physical AI。该文件不绑定当前项目模块。
