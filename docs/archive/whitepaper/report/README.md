## 材料来源

- 原始项目方案：`docs/project/`
- 白皮书设计依据：`docs/specs/2026-05-30-焊接经验结构化论证白皮书-design.md`
- 实施计划：`docs/plans/2026-05-30-焊接经验结构化POC与论证白皮书.md`
- POC 代码与自审：`weld-experience-engine/`
- 白皮书引用的 POC 证据快照：`report/data/` 与 `report/assets/`

## 使用原则

1. `docs/` 保持为资料库。
2. `weld-experience-engine/` 保持为可运行 POC。
3. `report/` 只放正式论证成果、白皮书引用素材和交付导出物。
4. 白皮书必须服务平台建设，不写成泛泛的智能制造宣传材料。
