# 仿真输出接入与经验沉淀平台 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the first platform I/O loop that imports simulation output bundles, validates them against the approved input-spec gate, converts them into `SyntheticSkillDataset v2`, and emits auditable evidence reports.

**Architecture:** Add a narrow `weldcore.ingest` boundary for bundle schema, gate, and conversion. Keep core models simulator-agnostic; `simlite` creates mock bundles for stable tests while ManiSkill/Isaac remain optional adapter directions. Preserve prior research artifacts and update documentation only where it clarifies the new simulation-ingest route.

**Tech Stack:** Python 3.10+, dataclasses, enum, csv/json/pathlib, pytest, existing `weldcore.model`, `weldcore.knowledge.synthetic_manifest`, `weldcore.report`, Markdown docs.

---

## 0. Scope Boundary

Design spec:

- `docs/superpowers/specs/2026-06-03-仿真输出接入与经验沉淀平台-design.md`

This plan implements the **simulation output ingestion and experience persistence loop only**.

It does:

- Define `SimulationOutputBundle` v0.1 schema and gate.
- Define `SimulationRunRecord`.
- Import one bundle, tied to one `SimulationInputSpec.input_id`, with one or more samples.
- Convert imported samples into existing `SkillDataset` / `SkillSample` structures using `schema_version = "synthetic-v2-dataset-v0.1"`.
- Preserve `input_id`, `taxonomy_ref`, `simulation_run_id`, assumptions, artifact refs, and evidence information.
- Generate a simulation-ingest evidence report.
- Use mock/simlite bundle output for stable tests.
- Update README/details language to say the platform now has a simulation output ingest path, not real-quality validation.

It does not:

- Implement a full ManiSkill/Isaac task environment.
- Add `mani_skill`, Isaac, ROS, or simulator SDKs as base dependencies.
- Generate large-scale `SyntheticSkillDataset v2`.
- Implement production database, UI, auth, upload API, robot control, welder control, MES/PLM/QMS interfaces.
- Claim real welding quality, WPS/PQR, ship-class approval, or molten-pool/in-process closed-loop capability.
- Delete prior research artifacts.

## 2. Success Criteria

Complete means all of these are true:

- `SimulationOutputBundle` v0.1 schema exists and is represented in code.
- `SimulationRunRecord` exists and serializes to JSON-friendly dicts.
- Bundle gate accepts a valid single-input/multi-sample bundle.
- Bundle gate rejects:
  - missing `manifest.json`;
  - wrong `schema_version`;
  - non-`simulation` `source_type`;
  - unknown `input_id`;
  - non-ready input task;
  - taxonomy mismatch;
  - missing `trajectory.csv`;
  - missing `process_signals.csv`;
  - missing required canonical columns;
  - process signal nulls without `missing_signal_notes`;
  - missing `evidence_bindings.json`;
  - current-stage forbidden terms: `熔池`, `molten_pool`, `molten pool`, `weld_pool`, `weld pool`;
  - quality placeholders without `requires_real_validation_later` or `simulation_score_placeholder`.
- Import converts a valid bundle into `SkillDataset` with:
  - `source_type = SourceType.SIMULATION`;
  - `schema_version = "synthetic-v2-dataset-v0.1"`;
  - one or more `SkillSample`;
  - preserved trajectory and process signals;
  - preserved `input_id`, `taxonomy_ref`, `simulation_run_id`, assumption summary, artifact refs, and evidence metadata.

from __future__ import annotations

from dataclasses import asdict, dataclass, field
from enum import Enum
from typing import Any


SIMULATION_BUNDLE_SCHEMA_VERSION = "synthetic-v2-bundle-v0.1"
SYNTHETIC_DATASET_SCHEMA_VERSION = "synthetic-v2-dataset-v0.1"


class SimulatorName(str, Enum):
    SIMLITE = "simlite"
    MANISKILL = "maniskill"
    ISAAC_SIM = "isaac_sim"
    ISAAC_LAB = "isaac_lab"
    SAPIEN = "sapien"
    OTHER = "other"


class SimulationRunStatus(str, Enum):
    CREATED = "created"
    RUNNING = "running"
    COMPLETED = "completed"
    FAILED = "failed"
    IMPORTED = "imported"


def _jsonable(value: Any) -> Any:
    if isinstance(value, Enum):
        return value.value
    if isinstance(value, list):
        return [_jsonable(item) for item in value]
    if isinstance(value, dict):
        return {key: _jsonable(item) for key, item in value.items()}
    return value


@dataclass(frozen=True)
class SimulationBundleManifest:
    bundle_id: str
    simulation_run_id: str
    input_id: str
    taxonomy_ref: str
    simulator: SimulatorName
    simulator_version: str
    adapter_version: str
    seed: int
    sample_count: int
    generated_at: str
    assumption_summary: list[str]
    requires_real_validation_later: bool
    missing_signal_notes: list[str]
    generation_boundary: list[str]
    source_type: str = "simulation"
    schema_version: str = SIMULATION_BUNDLE_SCHEMA_VERSION

    def to_dict(self) -> dict[str, Any]:
        return {key: _jsonable(value) for key, value in asdict(self).items()}


@dataclass(frozen=True)
class SimulationRunRecord:
    simulation_run_id: str
    input_ids: list[str]
    simulator: SimulatorName
    simulator_version: str
    adapter_name: str
    adapter_version: str
    seed: int
    started_at: str
    finished_at: str
    status: SimulationRunStatus
    output_bundle_uris: list[str]
    sample_count: int
    warnings: list[str] = field(default_factory=list)
    errors: list[str] = field(default_factory=list)
    boundary_notes: list[str] = field(default_factory=list)

    def to_dict(self) -> dict[str, Any]:
        return {key: _jsonable(value) for key, value in asdict(self).items()}
```

@dataclass(frozen=True)

def _read_json(path: Path) -> Any:

def _csv_columns(path: Path) -> set[str]:
    with path.open(encoding="utf-8", newline="") as handle:
        reader = csv.DictReader(handle)
        return set(reader.fieldnames or [])


def _contains_forbidden_terms(value: Any) -> bool:
    text = json.dumps(value, ensure_ascii=False).lower()
    return any(term in text for term in FORBIDDEN_POOL_TERMS)


def _bundle_text_contains_forbidden_terms(bundle: Path) -> bool:
    for path in bundle.rglob("*"):
        if not path.is_file():
            continue
        try:
            text = path.read_text(encoding="utf-8").lower()
        except UnicodeDecodeError:
            continue
        if any(term in text for term in FORBIDDEN_POOL_TERMS):
            return True
    return False


def _sample_ids_from_csv(path: Path) -> set[str]:
    with path.open(encoding="utf-8", newline="") as handle:
        return {row["sample_id"] for row in csv.DictReader(handle) if row.get("sample_id")}


def _quality_placeholders_have_boundary(quality: dict[str, Any]) -> bool:
    if quality.get("requires_real_validation_later") is True:
        return True
    return quality.get("quality_label") == "simulation_score_placeholder"


def validate_simulation_bundle(
    bundle_dir: str | Path,
    foundation: SyntheticInputFoundation | None = None,
) -> SimulationBundleGateResult:
    bundle = Path(bundle_dir)
    issues: list[str] = []
    synthetic_foundation = foundation or load_synthetic_input_foundation()
    input_by_id = {
        simulation_input.input_id: simulation_input
        for simulation_input in synthetic_foundation.simulation_inputs
    }

    manifest_path = bundle / "manifest.json"
    if not manifest_path.exists():
        return SimulationBundleGateResult(False, ["missing manifest.json"])
    manifest = _read_json(manifest_path)

    if manifest.get("schema_version") != SIMULATION_BUNDLE_SCHEMA_VERSION:
        issues.append("wrong schema_version")
    if manifest.get("source_type") != "simulation":
        issues.append("source_type must be simulation")
    if _contains_forbidden_terms(manifest):
        issues.append("forbidden pool-route term is out of scope")
    if _bundle_text_contains_forbidden_terms(bundle):
        issues.append("forbidden pool-route term is out of scope")

    input_id = manifest.get("input_id")
    simulation_input = input_by_id.get(input_id)
    if simulation_input is None:
        issues.append(f"unknown input_id {input_id}")
    elif manifest.get("taxonomy_ref") != simulation_input.taxonomy_ref:
        issues.append("taxonomy_ref does not match input spec")
    else:
        taxonomy_by_id = {entry.family_id: entry for entry in synthetic_foundation.task_taxonomy}
        taxonomy = taxonomy_by_id.get(simulation_input.taxonomy_ref)
        if taxonomy is None:
            issues.append(f"unknown taxonomy_ref {simulation_input.taxonomy_ref}")
        elif not taxonomy.ready_for_plan():
            issues.append(f"taxonomy_ref {simulation_input.taxonomy_ref} is not ready_for_synthetic_v2_plan")

    trajectory_path = bundle / "trajectory.csv"
    if not trajectory_path.exists():
        issues.append("missing trajectory.csv")
    else:
        missing = REQUIRED_TRAJECTORY_COLUMNS - _csv_columns(trajectory_path)
        if missing:
            issues.append(f"trajectory.csv missing columns: {sorted(missing)}")

    process_path = bundle / "process_signals.csv"
    if not process_path.exists():
        issues.append("missing process_signals.csv")
    else:
        missing = REQUIRED_PROCESS_COLUMNS - _csv_columns(process_path)
        if missing:
            issues.append(f"process_signals.csv missing columns: {sorted(missing)}")

    if not (bundle / "evidence_bindings.json").exists():
        issues.append("missing evidence_bindings.json")
    quality_path = bundle / "quality_placeholders.json"
    if not quality_path.exists():
        issues.append("missing quality_placeholders.json")
    else:
        quality = _read_json(quality_path)
        if not isinstance(quality, dict) or not _quality_placeholders_have_boundary(quality):
            issues.append("quality placeholders require boundary")
    if not manifest.get("requires_real_validation_later"):
        issues.append("requires_real_validation_later must be true for synthetic ingest")

    if trajectory_path.exists():
        sample_ids = _sample_ids_from_csv(trajectory_path)
        if manifest.get("sample_count") != len(sample_ids):
            issues.append("sample_count does not match trajectory sample ids")

    return SimulationBundleGateResult(not issues, issues)
```

def write_simlite_bundle(

    bundle.mkdir(parents=True, exist_ok=True)

    manifest = {
        "bundle_id": bundle_id,

        "input_id": input_id,
        "taxonomy_ref": simulation_input.taxonomy_ref,
        "simulator": "simlite",

        "schema_version": SIMULATION_BUNDLE_SCHEMA_VERSION,
        "assumption_summary": [

        "requires_real_validation_later": True,
        "missing_signal_notes": [],
        "generation_boundary": [

from __future__ import annotations

import argparse
import json
from pathlib import Path
from typing import Any

from weldcore.ingest import import_simulation_bundle
from weldcore.knowledge.manifest import DEFAULT_FOUNDATION_ROOT
from weldcore.knowledge.synthetic_manifest import load_synthetic_input_foundation
from weldcore.sim.bundle import write_simlite_bundle


DEFAULT_DOCS_REPORT_DIR = DEFAULT_FOUNDATION_ROOT / "reports"


def _write_json(path: Path, data: Any) -> None:
    path.write_text(json.dumps(data, ensure_ascii=False, indent=2), encoding="utf-8")


def run_simulation_ingest_report(
    outdir: str | Path = "simulation_ingest_report_out",
    docs_report_dir: str | Path | None = None,
    input_id: str = "input-panel-butt-001",
) -> dict[str, Any]:
    outpath = Path(outdir)
    outpath.mkdir(parents=True, exist_ok=True)

    foundation = load_synthetic_input_foundation()
    bundle = write_simlite_bundle(
        outpath / "bundles",
        input_id=input_id,
        sample_count=1,
        seed=7,
        foundation=foundation,
    )
    imported = import_simulation_bundle(bundle, foundation=foundation)

    manifest = json.loads((bundle / "manifest.json").read_text(encoding="utf-8"))
    run_record = imported.run_record.to_dict()
    dataset = imported.dataset.to_dict()
    simulation_input = next(
        item for item in foundation.simulation_inputs if item.input_id == manifest["input_id"]
    )
    evidence_bindings = [
        binding.to_dict() for binding in simulation_input.evidence_bindings
    ]
    assumption_bindings = [
        item for item in evidence_bindings if item["value_status"] in {"assumed", "generated", "unknown"}
    ]
    real_validation_bindings = [
        item for item in evidence_bindings if item["value_status"] == "requires_real_validation_later"
    ]
    summary = {
        "simulation_run_id": imported.run_record.simulation_run_id,
        "bundle_id": manifest["bundle_id"],
        "input_id": manifest["input_id"],
        "taxonomy_ref": manifest["taxonomy_ref"],
        "sample_count": len(imported.dataset.samples),
        "dataset_id": imported.dataset.dataset_id,
        "evidence_binding_count": len(evidence_bindings),
        "assumption_field_count": len(assumption_bindings),
        "real_validation_field_count": len(real_validation_bindings),
        "can_extract_skill_package": bool(imported.dataset.samples),
    }
    sample_summary = [
        {
            "sample_id": sample.sample_id,
            "trajectory_points": len(sample.trajectory.samples),
            "process_signal_points": len(sample.process_signals),
            "validation_status": sample.metadata.get("validation_status", "requires_real_validation_later"),
        }
        for sample in imported.dataset.samples
    ]
    evidence = {
        "summary": summary,
        "run_record": run_record,
        "bundle_manifest": manifest,
        "dataset": dataset,
        "sample_summary": sample_summary,
        "input_alignment": {
            "input_id": manifest["input_id"],
            "taxonomy_ref": manifest["taxonomy_ref"],
            "schema_version": manifest["schema_version"],
            "source_type": manifest["source_type"],
        },
        "evidence_bindings": evidence_bindings,
        "assumption_bindings": assumption_bindings,
        "real_validation_bindings": real_validation_bindings,
        "warnings": run_record.get("warnings", []),
        "errors": run_record.get("errors", []),
    }

    _write_json(outpath / "run_record.json", run_record)
    _write_json(outpath / "bundle_manifest.json", manifest)
    _write_json(outpath / "dataset.json", dataset)
    _write_markdown(outpath / "evidence.md", evidence)

    if docs_report_dir is not None:
        docs_path = Path(docs_report_dir)
        docs_path.mkdir(parents=True, exist_ok=True)
        _write_markdown(docs_path / "simulation_ingest_evidence.md", evidence)

    print("=== 仿真输出接入证据摘要 ===")
    print(f"仿真运行: {summary['simulation_run_id']}")
    print(f"输入规范: {summary['input_id']}")
    print(f"任务族: {summary['taxonomy_ref']}")
    print(f"样本数: {summary['sample_count']}")
    print(f"报告目录: {outpath}")
    return evidence


def _write_markdown(path: Path, evidence: dict[str, Any]) -> None:
    summary = evidence["summary"]
    input_alignment = evidence["input_alignment"]
    lines = [
        "# 仿真输出接入证据报告",
        "",
        "## Summary",

        "",
        f"- 仿真运行：{summary['simulation_run_id']}",
        f"- bundle：{summary['bundle_id']}",
        f"- 输入规范：{summary['input_id']}",
        f"- 任务族：{summary['taxonomy_ref']}",
        f"- 样本数：{summary['sample_count']}",
        f"- 数据集：{summary['dataset_id']}",
        f"- 证据绑定数：{summary['evidence_binding_count']}",
        f"- 假设/生成字段数：{summary['assumption_field_count']}",
        f"- 后续真实验证字段数：{summary['real_validation_field_count']}",
        "",
        "## Run Summary",
        "",
        f"- simulation_run_id：{evidence['run_record']['simulation_run_id']}",
        f"- simulator：{evidence['run_record']['simulator']}",
        f"- status：{evidence['run_record']['status']}",
        f"- output bundles：{len(evidence['run_record']['output_bundle_uris'])}",
        "",
        "## Bundle Summary",
        "",
        f"- bundle_id：{evidence['bundle_manifest']['bundle_id']}",
        f"- schema_version：{evidence['bundle_manifest']['schema_version']}",
        f"- input_id：{evidence['bundle_manifest']['input_id']}",
        f"- taxonomy_ref：{evidence['bundle_manifest']['taxonomy_ref']}",
        f"- sample_count：{evidence['bundle_manifest']['sample_count']}",
        "",
        "## Sample Summary",

        *[
            f"- {item['sample_id']}｜trajectory={item['trajectory_points']}｜process={item['process_signal_points']}｜validation={item['validation_status']}"
            for item in evidence["sample_summary"]
        ],
        "",
        "## Input Spec Alignment",
        "",
        f"- input_id：{input_alignment['input_id']}",
        f"- taxonomy_ref：{input_alignment['taxonomy_ref']}",
        f"- bundle schema：{input_alignment['schema_version']}",
        f"- source_type：{input_alignment['source_type']}",
        "",
        "## Evidence Binding Summary",

        "",
        "## Assumption Fields",

        "- 前期调研资料继续作为后续焊接知识嵌入底座。",
    ]
    path.write_text("\n".join(lines) + "\n", encoding="utf-8")


def main(argv: list[str] | None = None) -> dict[str, Any]:
    parser = argparse.ArgumentParser(description="生成仿真输出接入证据报告。")
    parser.add_argument("--outdir", default="simulation_ingest_report_out")
    parser.add_argument("--input-id", default="input-panel-butt-001")
    parser.add_argument(
        "--docs-report-dir",
        default=str(DEFAULT_DOCS_REPORT_DIR),
        help="同步刷新的 docs 报告目录。",
    )
    parser.add_argument(
        "--no-docs-copy",
        action="store_true",
        help="只写 runtime 输出目录，不刷新 docs 报告副本。",
    )
    args = parser.parse_args(argv)
    docs_report_dir = None if args.no_docs_copy else args.docs_report_dir
    return run_simulation_ingest_report(
        outdir=args.outdir,
        docs_report_dir=docs_report_dir,
        input_id=args.input_id,
    )


if __name__ == "__main__":
    main()
