# 数据集与资料底座 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a manifest-first data foundation that turns public welding sources, public datasets, field coverage, and shipbuilding task evidence into executable gates and a downstream `SyntheticSkillDataset v2` planning input.

**Architecture:** Add a small `weldcore.knowledge.foundation` model layer, manifest loaders under `weldcore.knowledge.manifest`, and one `data_foundation_report` command. Human-readable cards live under `docs/data-foundation/`; machine-readable JSON/CSV manifests are the single source of truth for gates and reports. This plan deliberately stops before generating bulk `SyntheticSkillDataset v2` samples.

**Tech Stack:** Python 3.10+, dataclasses, enum, json/csv/pathlib, pytest, existing `weldcore.report` conventions, Markdown/HTML docs.

## 0. Scope Boundary

Design spec:

- `docs/superpowers/specs/2026-06-01-数据集与资料底座-design.md`
- HTML reading copy: `docs/superpowers/specs/2026-06-01-数据集与资料底座-design.html`

This plan implements the **manifest-first data foundation** for that spec.

It does:

- Create `SourceCard`, `DatasetCard`, `FieldCoverageRow`, `TaskEvidenceEntry`, and `DataFoundation` models.
- Create `docs/data-foundation/` Markdown cards and JSON/CSV manifests.
- Load manifests into executable Python objects.
- Enforce source, dataset, field coverage, task readiness, and forbidden-field gates.
- Generate `data_foundation_report` artifacts.
- Generate a downstream `SyntheticSkillDataset v2` planning input document.
- Update README and `details.md`.

It does not:

- Download large public datasets into git.
- Generate bulk `SyntheticSkillDataset v2` samples.
- Implement robot programs, real-machine adapters, or production UI.
- Add molten-pool, weld-pool, or closed-loop in-process control dependencies.

## 2. Success Criteria

Complete means all of these are true:

- `docs/data-foundation/` exists with readable source-card docs and machine-readable manifests.
- Manifest contains at least 20 total sources.
- Manifest contains at least 15 public sources.
- Manifest contains at least 8 sources with `shipbuilding_relevance_level = "strong"`.
- Manifest contains at least 6 public datasets, counted by `DatasetCard.source_id` pointing to a `SourceCard` with `public_access = "public"`.
- Every source has `usable_for`, `covered_fields`, `missing_fields`, `source_refs`, `assumptions`, `public_access`, `use_boundary`, and `notes`.
- `notes` is not accepted as a substitute for `use_boundary`.
- Every dataset has `modalities`, `size_note`, `download_policy`, `schema_summary`, `quality_label_type`, `shipbuilding_fit`, and `use_boundary`.
- Dataset `download_policy` never asks to download large files into git.
- At least 3 task evidence entries have `readiness = "ready_for_synthetic_v2_plan"`.
- Task evidence entries reference existing source ids and dataset ids.
- Each ready task has at least one strong shipbuilding source.
- Required task fields are either covered or explicitly listed in `assumption_fields`.
- JSON/CSV outputs contain no `熔池`, `molten_pool`, `molten pool`, `weld_pool`, or `weld pool` except negative tests and boundary text in Markdown.
- `data_foundation_report` raises clear errors when source, dataset, field, task, or forbidden-field gates fail.

from __future__ import annotations

from dataclasses import asdict, dataclass
from enum import Enum
from typing import Any


FORBIDDEN_POOL_TERMS = ("molten", "molten_pool", "molten pool", "weld_pool", "weld pool", "熔池")


class PublicAccess(str, Enum):
    PUBLIC = "public"
    PROJECT_INTERNAL = "project_internal"
    REQUIRES_SCREENING = "requires_screening"


class ShipbuildingRelevanceLevel(str, Enum):
    STRONG = "strong"
    ADJACENT = "adjacent"
    GENERIC = "generic"


class DownloadPolicy(str, Enum):
    MANIFEST_ONLY = "manifest_only"
    SAMPLE_CACHE_LATER = "sample_cache_later"
    EXTERNAL_CACHE_ONLY = "external_cache_only"


class DatasetModality(str, Enum):
    XRAY_IMAGE = "xray_image"
    SURFACE_IMAGE = "surface_image"
    CURRENT_VOLTAGE_TIMESERIES = "current_voltage_timeseries"
    ROBOT_POSE = "robot_pose"
    SCAN_3D = "scan_3d"
    VIDEO = "video"
    METADATA = "metadata"


class TaskReadiness(str, Enum):
    READY_FOR_SYNTHETIC_V2_PLAN = "ready_for_synthetic_v2_plan"
    NEEDS_MORE_SOURCES = "needs_more_sources"
    DEFER = "defer"


def _jsonable(value: Any) -> Any:
    if isinstance(value, Enum):
        return value.value
    if isinstance(value, list):
        return [_jsonable(item) for item in value]
    if isinstance(value, dict):
        return {key: _jsonable(item) for key, item in value.items()}
    return value


@dataclass(frozen=True)
class SourceCard:
    source_id: str
    source_type: str
    title: str
    url: str
    publisher: str
    public_access: PublicAccess
    shipbuilding_relevance_level: ShipbuildingRelevanceLevel
    shipbuilding_relevance: str
    covered_fields: list[str]
    missing_fields: list[str]
    usable_for: list[str]
    source_refs: list[str]
    assumptions: list[str]
    use_boundary: str
    notes: str

    def is_complete(self) -> bool:
        return all(
            [
                self.source_id,
                self.source_type,
                self.title,
                self.url,
                self.publisher,
                self.public_access,
                self.shipbuilding_relevance_level,
                self.shipbuilding_relevance,
                self.covered_fields,
                self.missing_fields,
                self.usable_for,
                self.source_refs,
                self.assumptions,
                self.use_boundary,
                self.notes,
            ]
        )

    def to_dict(self) -> dict[str, Any]:
        return {key: _jsonable(value) for key, value in asdict(self).items()}


@dataclass(frozen=True)
class DatasetCard:
    dataset_id: str
    source_id: str
    modalities: list[DatasetModality]
    size_note: str
    download_policy: DownloadPolicy
    schema_summary: str
    quality_label_type: str
    shipbuilding_fit: str
    use_boundary: str

    def is_complete(self) -> bool:
        return all(
            [
                self.dataset_id,
                self.source_id,
                self.modalities,
                self.size_note,
                self.download_policy,
                self.schema_summary,
                self.quality_label_type,
                self.shipbuilding_fit,
                self.use_boundary,
            ]
        )

    def to_dict(self) -> dict[str, Any]:
        return {key: _jsonable(value) for key, value in asdict(self).items()}


@dataclass(frozen=True)
class FieldCoverageRow:
    field_name: str
    source_ids: list[str]
    dataset_ids: list[str]
    coverage_role: str
    notes: str

    def to_dict(self) -> dict[str, Any]:
        return asdict(self)


@dataclass(frozen=True)
class TaskEvidenceEntry:
    family_id: str
    required_sources: list[str]
    supporting_source_ids: list[str]
    supporting_dataset_ids: list[str]
    required_fields: list[str]
    covered_required_fields: list[str]
    assumption_fields: list[str]
    readiness: TaskReadiness
    next_action: str

    def ready_for_plan(self) -> bool:
        return self.readiness == TaskReadiness.READY_FOR_SYNTHETIC_V2_PLAN

    def to_dict(self) -> dict[str, Any]:
        return {key: _jsonable(value) for key, value in asdict(self).items()}


@dataclass(frozen=True)
class DataFoundationGateResult:
    passed: bool
    issues: list[str]


@dataclass
class DataFoundation:
    sources: list[SourceCard]
    datasets: list[DatasetCard]
    task_evidence: list[TaskEvidenceEntry]
    field_coverage: list[FieldCoverageRow] | None = None

    def validate(self) -> DataFoundationGateResult:
        issues: list[str] = []
        for source in self.sources:
            if not source.is_complete():
                issues.append(f"{source.source_id}: incomplete source card")
            text = str(source.to_dict()).lower()
            if any(term in text for term in FORBIDDEN_POOL_TERMS):
                issues.append(f"{source.source_id}: molten-pool dependency is out of scope")
        for dataset in self.datasets:
            if not dataset.is_complete():
                issues.append(f"{dataset.dataset_id}: incomplete dataset card")
        return DataFoundationGateResult(not issues, issues)
```

from __future__ import annotations

import csv
import json
from pathlib import Path

from .foundation import (
    DataFoundation,
    DatasetCard,
    DatasetModality,
    DownloadPolicy,
    FieldCoverageRow,
    PublicAccess,
    ShipbuildingRelevanceLevel,
    SourceCard,
    TaskEvidenceEntry,
    TaskReadiness,
)


DEFAULT_FOUNDATION_ROOT = Path(__file__).resolve().parents[3] / "docs" / "data-foundation"


def _load_json(path: Path):
    return json.loads(path.read_text(encoding="utf-8"))


def _source_from_dict(data: dict) -> SourceCard:
    return SourceCard(
        source_id=data["source_id"],
        source_type=data["source_type"],
        title=data["title"],
        url=data["url"],
        publisher=data["publisher"],
        public_access=PublicAccess(data["public_access"]),
        shipbuilding_relevance_level=ShipbuildingRelevanceLevel(
            data["shipbuilding_relevance_level"]
        ),
        shipbuilding_relevance=data["shipbuilding_relevance"],
        covered_fields=list(data["covered_fields"]),
        missing_fields=list(data["missing_fields"]),
        usable_for=list(data["usable_for"]),
        source_refs=list(data["source_refs"]),
        assumptions=list(data["assumptions"]),
        use_boundary=data["use_boundary"],
        notes=data["notes"],
    )


def _dataset_from_dict(data: dict) -> DatasetCard:
    return DatasetCard(
        dataset_id=data["dataset_id"],
        source_id=data["source_id"],
        modalities=[DatasetModality(item) for item in data["modalities"]],
        size_note=data["size_note"],
        download_policy=DownloadPolicy(data["download_policy"]),
        schema_summary=data["schema_summary"],
        quality_label_type=data["quality_label_type"],
        shipbuilding_fit=data["shipbuilding_fit"],
        use_boundary=data["use_boundary"],
    )


def _task_entry_from_dict(data: dict) -> TaskEvidenceEntry:
    return TaskEvidenceEntry(
        family_id=data["family_id"],
        required_sources=list(data["required_sources"]),
        supporting_source_ids=list(data["supporting_source_ids"]),
        supporting_dataset_ids=list(data["supporting_dataset_ids"]),
        required_fields=list(data["required_fields"]),
        covered_required_fields=list(data["covered_required_fields"]),
        assumption_fields=list(data["assumption_fields"]),
        readiness=TaskReadiness(data["readiness"]),
        next_action=data["next_action"],
    )


def _load_field_coverage(path: Path) -> list[FieldCoverageRow]:
    rows = []
    with path.open(encoding="utf-8", newline="") as f:
        for row in csv.DictReader(f):
            rows.append(
                FieldCoverageRow(
                    field_name=row["field_name"],
                    source_ids=[item for item in row["source_ids"].split(";") if item],
                    dataset_ids=[item for item in row["dataset_ids"].split(";") if item],
                    coverage_role=row["coverage_role"],
                    notes=row["notes"],
                )
            )
    return rows


def load_data_foundation(root: str | Path | None = None) -> DataFoundation:
    base = Path(root) if root is not None else DEFAULT_FOUNDATION_ROOT
    manifests = base / "manifests"
    return DataFoundation(
        sources=[_source_from_dict(item) for item in _load_json(manifests / "sources.json")],
        datasets=[_dataset_from_dict(item) for item in _load_json(manifests / "datasets.json")],
        task_evidence=[
            _task_entry_from_dict(item)
            for item in _load_json(manifests / "task_evidence_map.json")
        ],
        field_coverage=_load_field_coverage(manifests / "field_coverage.csv"),
    )
```

```python
from __future__ import annotations

import csv
import json
import argparse
from pathlib import Path
from typing import Any

from ..knowledge.foundation import DataFoundation, PublicAccess, ShipbuildingRelevanceLevel
from ..knowledge.manifest import DEFAULT_FOUNDATION_ROOT, load_data_foundation


DEFAULT_DOCS_REPORT_DIR = DEFAULT_FOUNDATION_ROOT / "reports"


def _write_json(path: Path, data: Any) -> None:
    path.write_text(json.dumps(data, ensure_ascii=False, indent=2), encoding="utf-8")


def _summary(foundation: DataFoundation) -> dict[str, int]:
    sources_by_id = {source.source_id: source for source in foundation.sources}
    return {
        "source_count": len(foundation.sources),
        "public_source_count": sum(
            source.public_access == PublicAccess.PUBLIC for source in foundation.sources
        ),
        "strong_shipbuilding_source_count": sum(
            source.shipbuilding_relevance_level == ShipbuildingRelevanceLevel.STRONG
            for source in foundation.sources
        ),
        "dataset_count": len(foundation.datasets),
        "public_dataset_count": sum(
            sources_by_id.get(dataset.source_id)
            and sources_by_id[dataset.source_id].public_access == PublicAccess.PUBLIC
            for dataset in foundation.datasets
        ),
        "ready_task_count": sum(entry.ready_for_plan() for entry in foundation.task_evidence),
    }


def run_data_foundation_report(
    outdir: str | Path = "data_foundation_report_out",
    foundation: DataFoundation | None = None,
    docs_report_dir: str | Path | None = None,
) -> dict[str, Any]:
    outpath = Path(outdir)
    outpath.mkdir(parents=True, exist_ok=True)

    data = foundation or load_data_foundation()
    gate = data.validate()
    if not gate.passed:
        raise ValueError("Data foundation gate failed: " + "; ".join(gate.issues))

    evidence = {
        "summary": _summary(data),
        "sources": [source.to_dict() for source in data.sources],
        "datasets": [dataset.to_dict() for dataset in data.datasets],
        "field_coverage": [row.to_dict() for row in data.field_coverage or []],
        "task_evidence": [entry.to_dict() for entry in data.task_evidence],
    }

    _write_json(outpath / "sources.json", evidence["sources"])
    _write_json(outpath / "datasets.json", evidence["datasets"])
    _write_json(outpath / "task_evidence_map.json", evidence["task_evidence"])

    with (outpath / "field_coverage.csv").open("w", encoding="utf-8", newline="") as f:
        writer = csv.writer(f)
        writer.writerow(["field_name", "source_ids", "dataset_ids", "coverage_role", "notes"])
        for row in data.field_coverage or []:
            writer.writerow(
                [
                    row.field_name,
                    ";".join(row.source_ids),
                    ";".join(row.dataset_ids),
                    row.coverage_role,
                    row.notes,
                ]
            )

    _write_evidence_markdown(outpath / "evidence.md", evidence)
    _write_plan_input(outpath / "synthetic_skilldataset_v2_plan_input.md", data)
    if docs_report_dir is not None:
        docs_path = Path(docs_report_dir)
        docs_path.mkdir(parents=True, exist_ok=True)
        _write_evidence_markdown(docs_path / "data_foundation_evidence.md", evidence)
        _write_plan_input(docs_path / "synthetic_skilldataset_v2_plan_input.md", data)

    print("=== 数据集与资料底座证据摘要 ===")
    print(f"来源: {evidence['summary']['source_count']}")
    print(f"公开来源: {evidence['summary']['public_source_count']}")
    print(f"船舶强相关: {evidence['summary']['strong_shipbuilding_source_count']}")
    print(f"公开数据集: {evidence['summary']['public_dataset_count']}")
    print(f"Ready task families: {evidence['summary']['ready_task_count']}")
    print(f"报告目录: {outpath}")
    if docs_report_dir is not None:
        print(f"提交版报告目录: {Path(docs_report_dir)}")
    return evidence
```
